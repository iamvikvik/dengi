# Мои деньги (бежевое стекло)

Загрузи в репозиторий dengi все файлы из этой папки, заменив старые:
index.html, manifest.webmanifest, sw.js, logo.png, icon-192.png, icon-512.png, apple-touch-icon.png

Старые bunny.png и pig.png больше не нужны, их можно удалить.
Данные не пропадут: они лежат в телефоне, формат прежний.
После загрузки открой приложение дважды (первый раз оно обновится само).
Сразу сделай копию: шестерёнка → «Сохранить копию».
